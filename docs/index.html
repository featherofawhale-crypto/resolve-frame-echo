01 / WHAT IT DOES

每一帧，都能停住一点余韵。

抽帧保持决定节奏；重影从历史帧归一化混合；慢快门沿运动方向延展。强度降低时依然保留抽帧的卡顿感，中心保护可避免重要主体被整体糊掉。

抽帧与拖影

目标帧率或每 N 帧更新。支持 2、4、8 层历史重影，以及慢快门模式。

定向与放射模糊

可选同方向拖动或从中心向外拉开的放射模糊，模糊中心可动画。

原生中心保护

椭圆、钢笔、矩形、圆角矩形、菱形和带状预设，全部来自 Fusion 原生节点。

02 / ANIMATE

虚影跟着动画走。

内置 Fusion Transform 在所有历史采样之前工作。位置、缩放、旋转和锚点均能打关键帧；不开启时会自动旁路，不额外占用历史采样的变换计算。

03 / INSTALL

三步安装。

下载 .drfx

从 GitHub Releases 下载最新完整包或单独 `.drfx`。

导入 Resolve

双击 `.drfx`，确认安装到效果库。

添加到片段

在效果库的 Frame Echo 分类中找到“抽帧拖影 Frame Echo”。

04 / PERFORMANCE

先保留节奏，再控制开销。

需要更轻的实时预览时：选“重影叠加”、设为 2 层，并关闭“附加运动模糊”。慢快门会使用 Optical Flow，是最重的模式。
